# 江津ドットGP

A1市街地グランプリ GOTSU を応援する、ファミコン風のドットレースゲームです（非公式）。

- 遊ぶ: https://gotsu-dot-gp.kosen-venture.com/
- コース: 2020年大会の市街地コース（パレットごうつ駐車場前スタート、国道9号・県道江津港線・駅前の市道、1周約778m・6コーナー・左回り）を地図データから再現しています。2026年大会のコースは調整中のため、実際とは異なる場合があります。
- ランキング: Firebase（Cloud Firestore）に保存します。書き込みルールは `firestore.rules` にあります。
- 地図データ © OpenStreetMap contributors (ODbL)
- 大会公式サイト: https://a1citygp.com/
